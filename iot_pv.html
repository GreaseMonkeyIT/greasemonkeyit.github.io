Project Evolution

From Paper to Digital Twin

This project began as an effort to expand the scope of our Smart India Hackathon (SIH) 2024 software stack developed for Problem Statement SIH1739 (ISRO/VEDAS). While exploring practical photovoltaic monitoring and data acquisition systems, we drew inspiration from an IEEE paper on LoRaWAN-based PV condition monitoring presented at PEDES 2022 by researchers from the Singapore Institute of Technology. The paper established the hardware layer: custom 16-channel PCBs measuring panel voltage, current, and temperature via optically isolated ADCs, ESP-NOW mesh aggregation, and LoRa long-range uplink at -105 dBm RSSI in NLOS conditions. The paper explicitly called out anomaly detection and irradiance prediction as future work. That gap became the scope of this project.

Phase 1 — Hardware Basis
LoRaWAN Sensor Network (Reference Architecture)
Custom circuit for single panel; using HCPL-7840 optical isolation amplifier for DC voltage (0-50V, 99.5% accuracy), Hall-effect current sensor CYCT03-L20 (97.1%), PT100 RTD with MAX31865 (98.7%), ADS1115 to convert analog voltage to digital logic-level. ESP32-S3 used as the primary microcontroller. LoRaWAN uplink via SX1278 + antenna setup for 1 km range. Self-powered from 12V 2Ah lead-acid with solar charge controller. Total node power: 0.5-0.8 W.
Phase 2 — PVGIS Data Foundation
ERA5 Weather Baseline + 10-City TMY Integration
Tested with Typical Meteorological Year data for 10 major Indian cities. Per-city optimal tilt and azimuth fetched from PVGIS-ERA5 at startup. Horizon obstruction profiles loaded from city-named CSVs and injected as userhorizon params. Lookup table indexed by (month, hour): mean power kW, P10, P90, mean irradiance W/m², mean temp. Background thread ingests today's intraday data every 5 minutes via ERA5 historical endpoint.
Phase 3 — Physics-Based Simulation
Single-Diode PV Model with NOCT Thermal Correction
Wrote the bespoke physics-based simulator around electrical models: System: 15 strings × 22 modules (100 kWp, c-Si, VOC=880V, ISC=147A). Cell temperature via NOCT model: T_cell = T_amb + (NOCT-20) × G/800. ISC scales linearly with G and has a positive temperature coefficient (+0.05%/°C). VOC is logarithmic in G with a strong negative temperature coefficient (-0.32%/°C). Each fault mode modifies ISC, VOC, and fill factor independently per its electrical signature.
Phase 4 — Anomaly Detection
K-Means + Physics-Based Fault Classifier
7-dimensional feature vector: normalised power, cyclic hour encoding (sin/cos), VOC/VOC,SYS, ISC/ISC,SYS, G/Gref, and VOC-to-ISC ratio (distinguishes bypass from string faults). K-Means (k=8) trained on 14+ days of bootstrapped intraday data. Anomaly score = z-score of distance to nearest centroid, threshold 1.5σ. Physics-based classifier reads which electrical parameters changed to identify fault type, rather than relying on output power alone.

Fault Detection

Physics-Based Fault Classifier

Most anomaly detection approaches flag deviations in output power and call the result a "fault." Our system goes further: each injected fault mode has a distinct electrical fingerprint derived from PV cell physics, and the classifier reads ISC, VOC, and fill factor independently to identify which mechanism failed.

Fault Mode Isc Voc FF Physical mechanism
String Anomaly -17% (3 of 15 strings) stable stable 3 strings at 15% Isc (shading/mismatch). Parallel bus holds VOC. ISC = (12 + 0.45)/15.
Bypass Diode +2% (lower Rs) -1.3% system-level -4% 8 modules with one shorted bypass diode (1/3 cells bypassed). Faulty string: 22×40 - 8×(40/3) = 773V vs 880V. System VOC averaged across 15 strings: (14×880 + 773)/15 = 869V.
Module Fault -20% (3 strings open) -3% -5% 3 strings open-circuit (combiner box failure). ISC = 12/15. Both ISC and VOC depressed.
Ground Fault -7% -1% (stable) -7% Insulation leakage: shunt path to ground lowers effective RSH, degrades ISC and FF. VOC roughly stable.
Gradual Degradation -1.5% -0.3% -1.2% EVA yellowing (ISC), metallisation corrosion + microcracking (FF). ~1.5%/yr diffuse decline.

Classifier decision logic

Physics-corrected normalisation — weather independent
Observed ISC, VOC, and FF are each divided by the healthy expected value at the reading's actual irradiance and cell temperature (from the same single-diode equations used by the simulator). A fault-free panel reads ~1.0 on all three at any weather condition:

norm_i = Isc_obs / Isc_exp(G, T_cell)
norm_v = Voc_obs / Voc_exp(G, T_cell)
norm_ff = FF_obs / FF_exp(T_cell)

Decision tree (evaluated in order):
norm_i < 0.85 AND norm_v < 0.985 → Module Fault (strings lost — both ISC and VOC depressed)
norm_i < 0.90 AND norm_v ≥ 0.985 → String Anomaly (current mismatch, VOC held by bus)
norm_ff < 0.98 AND norm_i ≥ 0.97 → Bypass Diode (FF drops, ISC normal/elevated)
norm_ff < 0.97 AND norm_i < 0.97 → Ground Fault (leakage: moderate ISC + FF loss)
otherwise → Gradual Degradation (diffuse, no dominant parameter signature)
ML Pipeline

K-Means Anomaly Detection

The pipeline bootstraps on 14 days of intraday data before activating. Once trained, every new reading is scored as a z-score of its distance to the nearest cluster centroid, normalised by that cluster's standard deviation. Scores above 1.5σ trigger the fault classifier. The model persists to disk between restarts.

Features — 7D
Feature Vector
norm_power: P/P_nameplate
hour_sin, hour_cos: cyclic time encoding
norm_voltage: Voc/Voc_exp(G,T); ~1.0 healthy
norm_current: Isc/Isc_exp(G,T); ~1.0 healthy
norm_irr: G/G_ref
voc_isc_ratio: norm_v/norm_i; separates bypass (VOC drops) from string (ISC drops)
Model
K-Means (k=8)
StandardScaler with per-feature std floor of 0.05; without it, norm_voltage/current/ratio (which are ~constant at 1.0 for a healthy array) have near-zero variance and the scaler divides by ~0, exploding fault deviations to hundreds of sigma. k-means++ initialisation, 10 restarts. Per-cluster distance stats computed post-fit. Anomaly score clamped to 0 minimum. Each city saves to its own pipeline_state_{city}.pkl: city-specific clusters, identical methodology.
Data
Ingestion
5-minute readings from the simulator, enriched with PVGIS expected output and performance gap. Background thread polls every 5 minutes. /api/ingest endpoint allows manual bootstrap of 30 days in one call. Night readings (G < 10 W/m² or power = 0) are excluded from training and scoring.
Scoring
Anomaly Score
z = max((dist - cluster_mean) / cluster_std, 0.0)
Threshold 1.5σ triggers fault classification. Score displayed live on the dashboard with a colour-coded bar (green/amber/red) and a 1.5σ threshold line on the intraday chart.
