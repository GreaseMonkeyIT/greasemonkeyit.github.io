Overview

A Self-Hosted NVR with Person-Specific Zone Alerting

A fully self-hosted network video recorder that runs YOLOv8n inference on CPU using Intel OpenVINO. Each camera runs two independent RTSP streams: a MJPEG sub-stream at CIF resolution for AI inference, and an H.264 sub-stream at D1 resolution for display and recording.

Inference is gated behind a MOG2 background subtraction motion detector: when the scene is idle, YOLOv8n never runs. When motion is detected, ByteTrack assigns persistent IDs to detected persons across frames, enabling a proper debounce + cooldown alert state machine; instead of simply firing an alert on every frame. ROI zones are user-defined.

Inference Pipeline

Dual-Stream Architecture

The core insight is that inference and display have different resolution requirements. Feeding a full D1 frame into YOLOv8n is wasteful, person detection works well even at CIF when using newer, mature models. By splitting the two tasks onto separate camera streams, the AI thread never competes with the display thread, allowing faster MJPEG decodes on ARM than H.264.

Components

System Breakdown

nvr.py
CameraStream
Daemon thread that continuously drains the RTSP buffer, always storing the latest decoded frame. Configurable output resolution and optional fps cap for RPi power management.
nvr.py
MOG2 Motion Gate
cv2.createBackgroundSubtractorMOG2 runs on every CIF frame before inference. If the foreground pixel count is below threshold, YOLOv8n is skipped entirely. Idle scenes cost near-zero CPU.
nvr.py
YOLOv8n OpenVINO
Exported to OpenVINO IR format at CIF resolution. INT8 for ARM (RPi4/5 — FP16 has no NEON acceleration), FP16 for x86. One model instance per camera to isolate ByteTrack state.
nvr.py
ByteTrack
Persistent cross-frame tracking via model.track(persist=True). Assigns stable IDs to detected persons so the alert system can reason about individuals, not raw detections.
nvr.py
ZoneAlert
Four-state machine: CLEAR → DEBOUNCE → ALERT → COOLDOWN. Requires 3 consecutive positive detections before raising an alert, then suppresses for 15 seconds after the last detection in zone.
nvr.py · Shapely
ROI Intersection
Polygon(zone_points).intersects(box(x1,y1,x2,y2)) — Shapely checks whether a detection bounding box overlaps the user-drawn zone. Zones are stored in cameras.yaml, updated live from the web UI.
nvr.py · Flask
Web UI
Flask server streams annotated D1 frames as browser-native MJPEG (multipart/x-mixed-replace). Canvas overlay handles ROI zone drawing — click to add vertices, right-click to undo, "Set Zone" to commit.
nvr.py
ClipRecorder
Maintains a 10-second circular pre-buffer of D1 frames per camera. On alert, flushes the pre-buffer to disk and continues recording for 15 seconds post-event. Output: clips/cam_N_timestamp.mp4.
nvr.py · paho-mqtt
MQTT Alerting
Publishes to nvr/cam_key/alert on state transitions only — CLEAR→ALERT and ALERT→COOLDOWN. Integrates with Home Assistant, Node-RED, or any MQTT subscriber. Gracefully disabled if broker is unreachable.
Alert Logic

Debounce + Cooldown State Machine

A naive implementation alerts on every detection frame, flooding downstream systems and creating false positives from momentary noise. The ZoneAlert state machine requires consecutive positive detections before committing to an alert, and enforces a cooldown window after the last detection, ensuring that MQTT fires only on state transitions, not per frame.

Implementation

MOG2 Gate + ByteTrack Inference

The inference loop runs per camera in its own thread. The MOG2 check runs on every frame; YOLOv8n only runs when the scene has meaningful motion.

# motion gate — cheap, runs every frame
if cv2.countNonZero(fgbg.apply(cif_frame)) < MOTION_THRESHOLD:
    det_state.update([], [], False)
    continue

# ByteTrack — only on motion events
results = model.track(
    cif_frame, persist=True,
    tracker="bytetrack.yaml", classes=[0],   # person only
    device='cpu', verbose=False
)

if results[0].boxes.id is not None:
    for box, tid in zip(results[0].boxes.xyxy, results[0].boxes.id):
        x1, y1, x2, y2 = (int(v) for v in box)
        if zone_poly and shapely_box(x1,y1,x2,y2).intersects(zone_poly):
            intruder_ids.append(int(tid))

# state machine — MQTT fires only on transitions
was_alert = zone_alert.state == AlertState.ALERT
is_alert  = zone_alert.update(intruder_ids, time.time())
if is_alert and not was_alert:
    mq.publish(f"nvr/{cam_key}/alert", json.dumps({"state": "ALERT"}))
Edge Inference

OpenVINO on CPU — x86 and ARM

The model is exported from yolov8n.pt directly to OpenVINO IR format using the Ultralytics export pipeline. Platform selection is automatic at runtime based on architecture detection.

On RPi, PERFORMANCE_HINT=LATENCY and INFERENCE_NUM_THREADS=3 are applied via an ov.Core.compile_model patch before any model is instantiated; leaving one core free for camera I/O threads and capping decode at 15fps to prevent RTSP saturating all cores.
